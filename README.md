## Project Overview

Seasonal Agriculture Performance Analysis is a data analytics project
that studies agricultural performance across different seasons, crops,
locations, environmental conditions, farming practices and economic factors.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains 4,000 farm-level records and 28 variables covering
agricultural, environmental, resource-use and economic attributes.
